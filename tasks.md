# Очередь задач автономного агента

Демон (`daemon.ps1`) берёт **первую** невыполненную задачу, выполняет её целиком,
прогоняет `pnpm verify` и коммитит. Одна задача за запуск.

Пометки: `[ ]` не сделано · `[x]` сделано · `[!]` задача неверна или невыполнима,
рядом строка почему.

Задачи писать **проверяемыми**: у каждой должно быть видно, чем доказывается,
что она выполнена. «Улучшить экран» — не задача, «привести экран оплаты
к раскладке экрана заказа и проверить замером, что нет целей меньше 44px» —
задача.

      `src-tauri/Cargo.toml`. Проверка: `pnpm verify`, `cargo check --release`,
      в `apps/desktop/src` нет ни одного упоминания `plugin-shell`.

- [ ] Убрать разрешение `shell:allow-execute` и блок `run-powershell`
      из `src-tauri/capabilities/default.json`. Оно осталось от прежней сборки
      и теперь ни к чему не привязано: выдавать из webview право запускать
      `powershell` с произвольными аргументами незачем. Проверка:
      `cargo check --release`, тестовая печать с экрана оборудования работает.
      Обновить абзац про это в `CLAUDE.md` — там сказано «строку стоит убрать».
      **Правки уже сделаны попутно с предыдущей задачей**: без снятого
      разрешения релиз не собирается вовсе («Permission shell:allow-execute
      not found»), так что блок из capabilities убран, абзац в `CLAUDE.md`
      переписан. Осталась одна непроверенная строка — тестовая печать
      с экрана оборудования на живой ККТ.

## Долги по коду

- [ ] Тест на идемпотентность `fiscal_configure`: повторный вызов с теми же
      адресом и портом **не должен** пересобирать устройство, иначе на стенде
      обнуляется открытая смена. Сейчас это поведение держится только
      комментарием. Проверка: `cargo test --lib`.

- [ ] Прокинуть `taxSystem` и `defaultVat` из карточки ККМ в чек возврата
      (`state/checkout.tsx`, ветка `refund`). Сейчас в продаже они берутся
      из карточки, а в возврате — по умолчанию, и документы расходятся.
      Проверка: `pnpm verify` плюс тест на состав чека возврата.
